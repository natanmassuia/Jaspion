Como abrir e restaurar os dados

  1. Abra checklist-qualidade-cem-v2.2.1.html no Microsoft Edge ou Google Chrome.
  2. Os dados deste computador são carregados automaticamente.
  3. Para restaurar dados, acesse Administração, clique em Carregar backup e escolha backup-checklist-cem.json.
Não é necessário conectar pastas nem abrir um arquivo de banco a cada uso.

Perguntas e lâminas

  • Os sete blocos solicitados já estão cadastrados, inicialmente sem perguntas.
  • Na Administração, apenas uma lâmina fica visível por vez. Use os indicadores ou os botões de navegação para trocar de setor.
  • Use + Adicionar pergunta dentro de qualquer lâmina.
  • Arraste as perguntas pelo controle ⋮⋮ para mudar a ordem. Para movê-las a outro setor, arraste até o indicador da lâmina desejada.
  • Use + Nova lâmina para criar outros blocos.
  • Cada pergunta exige uma resposta: Conforme, Não conforme, Não se aplica ou a quarta opção personalizável.
  • A observação é opcional e aparece somente ao clicar em + Observação.
  • Na lâmina Qualidade, marque Precisa de revisão? e informe o motivo quando necessário.

Integração com Google Sheets

  1. Abra a planilha de destino no Google Sheets e acesse Extensões › Apps Script.
  2. Cole o conteúdo de GoogleAppsScript_Code_v2.2.1.gs em Code.gs.
  3. No script, troque TOKEN por uma senha longa.
  4. Selecione Implantar › Nova implantação › Aplicativo da web.
  5. Configure “Executar como” você e permita acesso a qualquer pessoa com o link.
  6. Copie a URL terminada em /exec.
  7. No checklist, acesse Administração › Google Sheets, cole a URL, informe o mesmo token e salve.
  8. Use Testar integração e confirme o registro na planilha.

Histórico detalhado

  • Clique em qualquer linha de ticket para abrir ou fechar seus detalhes.
  • Os cards mostram conformidade, conformes, não conformes, não se aplica, parcialmente conforme e pendentes.
  • Os números e as linhas coloridas são animados conforme o resultado.
  • Use os indicadores de lâmina para consultar as respostas e observações de cada setor.
  • O botão Carregar leva o ticket novamente para a área de Avaliação.

Backup e mudança de computador

  • Clique em Baixar backup para gerar somente o arquivo backup-checklist-cem.json.
  • Guarde esse arquivo no local desejado. Ao gerar outro, substitua o arquivo anterior.
  • No novo computador, abra o HTML e use Carregar backup.
  • O histórico pode ser exportado separadamente em CSV.

Impressão e PDF

Durante uma avaliação, use Imprimir / Salvar PDF. Todas as lâminas são incluídas no documento, mesmo que apenas uma permaneça visível durante o preenchimento.

Migração entre versões do banco

Ao carregar um backup de uma versão anterior, o sistema identifica o número do esquema e executa automaticamente todas as migrações necessárias, uma após a outra, até chegar ao esquema atual.

  • O arquivo selecionado não é alterado; apenas uma cópia migrada é carregada no navegador.
  • O histórico de migrações fica registrado dentro do próprio banco.
  • Bancos de versões futuras não são alterados por uma versão antiga do sistema.
  • Detalhes técnicos estão em MIGRACOES_BANCO_v2.2.1.md.
