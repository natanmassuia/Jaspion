# Diretriz de entrega Dev e Produção

1. Toda alteração deve ser aplicada e validada primeiro em `M:\Noc\Everlin\Q.A\Qualidade\CheckList\Dev\Intranet_CCO_DEV`.
2. A pasta Dev é a fonte compartilhada de desenvolvimento e testes entre tarefas e abas.
3. Produção não deve ser alterada sem aprovação explícita do usuário.
4. Após aprovação, a versão validada em Dev deve ser promovida para `M:\Noc\Everlin\Q.A\Qualidade\CheckList\Produção`.
5. Produção deve manter somente a versão vigente. A versão substituída deve ser movida para `Arquivo`, sem exclusão.
6. Toda entrega de alteração deve incluir um ZIP completo para download, claramente identificado como DEV ou PROD.
